## 修复音乐播放器卡顿和滚动问题

### 问题
1. 加载有很多音乐的文件夹后会卡顿
2. 左边音乐栏不能滚动
3. 歌名显示逻辑需要检查
4. 添加音乐文件夹时需要 loading 状态

### 解决方案

#### 1. 修复卡顿问题
- 将音乐文件夹扫描改为后台线程执行
- 添加 `loading_folders: Vec<SharedString>` 字段跟踪加载状态
- 修改 `pick_music_folder()` 和 `load_music_folder()` 使用 `cx.spawn()` 和 `cx.background_spawn()` 在后台线程扫描

#### 2. 添加侧边栏滚动功能
- 在 `sidebar.rs` 中导入 `gpui_component::scroll::ScrollableElement`
- 使用 `.overflow_y_scrollbar()` 替代 `.overflow_scroll()` 添加垂直滚动条

#### 3. 检查歌名显示逻辑
- `audio.rs` 中的 `read_meta()` 已经正确处理：
  - 优先使用文件元数据中的歌名
  - 如果没有元数据，使用文件名（不含扩展名）
  - 如果文件名也无法获取，使用 "未知"

#### 4. 添加 loading 状态
- 在 `sidebar.rs` 中添加 loading 文件夹列表显示
- 显示 "⏳ 文件夹名" 和 "加载中..."
- 扫描完成后自动移除 loading 状态

### 修改的文件
- `src/main.rs` - 添加 `loading_folders` 字段，修改文件夹扫描逻辑
- `src/ui/sidebar.rs` - 添加滚动功能和 loading 状态显示
- `src/audio.rs` - 无需修改（已经正确处理歌名显示）

### 技术要点
- 使用 `cx.spawn()` 和 `cx.background_spawn()` 实现后台线程扫描
- 使用 `weak_entity` 避免在异步闭包中直接捕获实体
- 使用 `gpui_component::scroll::ScrollableElement` 实现滚动功能

## 实现虚拟滚动

### 问题
- 1366 首歌曲时滚动卡顿（一次性渲染所有项）
- 列表项无法显示封面（播放时能拿到，列表拿不到）

### 解决方案

#### 虚拟滚动（uniform_list）
- 使用 GPUI 的 `uniform_list` 实现虚拟滚动，只渲染可见项
- 把文件夹 header 和歌曲统一成 `ListItem` 枚举（FolderHeader/Track/Loading）
- 展平所有列表项到一个 `Vec<ListItem>`，用 `uniform_list` 渲染
- `uniform_list` 的 callback 签名是 `Fn(Range<usize>, &mut Window, &mut App)`，需要 `'static` 闭包
- 点击事件通过 `entity.downgrade()` + `entity.update(cx, |this, cx| ...)` 在 `&mut App` 上下文中处理
- 在 `&mut App` 上下文中 `entity.update()` 返回 `()`，不需要 `.ok()`

#### 封面延迟加载（未完成）
- 扫描时不提取封面（保持快速）
- 播放时提取封面并缓存到 `current_cover: Option<Arc<RenderImage>>`
- 列表项暂显示默认图标 "♪"

### 关于 Windows 文件管理器封面
- Windows 使用**系统缩略图缓存**（`thumbcache_*.db`），第一次访问生成并缓存
- 使用 Shell API（`SHGetFileInfo`）异步提取并利用系统缓存
- 我们的代码每次都要重新打开 MP3 文件解析元数据，没有缓存，所以慢

### 修改的文件
- `src/ui/sidebar.rs` - 完全重写，使用 `uniform_list` 实现虚拟滚动
- `src/ui/center.rs` - 修复封面图标居中（添加 `w_full().h_full()`）

### 技术要点
- `uniform_list(id, item_count, callback)` - callback 接收 `Range<usize>`
- `.with_sizing_behavior(gpui::ListSizingBehavior::Auto)` - 自动调整大小
- `ListItem` 枚举统一列表项类型，支持 Clone
- `entity.downgrade()` 在 'static 闭包中安全引用 entity
