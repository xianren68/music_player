## 封面懒加载
用户要求改为按需加载：只有歌曲滚动到可视区域时才提取封面，而不是启动时批量遍历。

### 实现
- 移除 `spawn_cover_loader()` 方法（原先遍历所有歌曲批量提取）
- `MusicPlayer` 添加 `loading_covers: HashSet<String>` 防止重复触发
- `build_sidebar` 的 processor 闭包中，渲染每首歌时检查 `cover_path.is_none()`
- 如果缓存文件不存在且未在加载中，`cx.spawn` 后台任务提取封面
- 提取完成后更新 `track.cover_path` 并 `save_settings_for_cache()` 持久化
- 播放时的主区域封面加载不受影响（仍在 `play()` 中即时加载）

### 修改的文件
- `src/main.rs` - 添加 loading_covers 字段，移除 spawn_cover_loader
- `src/ui/sidebar.rs` - processor 闭包中添加懒加载逻辑

## 封面加载防抖
用户反馈滚动时卡顿，要求快速滚动时不要加载封面，停下来再加载。

### 实现
- 添加 `pending_cover_loads: Vec<(fi, ti, path, key)>` — 待处理的封面加载队列
- 添加 `cover_debounce_gen: u64` — 防抖代数计数器
- processor 闭包中：不再立即 spawn 提取任务，而是收集到 `pending_cover_loads`
- 有新封面加入队列时递增 gen 并 spawn 一个 300ms 定时器
- 定时器到期时检查 gen 是否匹配，不匹配说明中间有新渲染，丢弃让新定时器处理
- 匹配时批量 drain `pending_cover_loads` 并 spawn 提取任务
- 快速滚动时 gen 不断被重置，只有停止滚动 300ms 后才会触发实际加载

### 修改的文件
- `src/main.rs` - 添加 pending_cover_loads、cover_debounce_gen 字段
- `src/ui/sidebar.rs` - processor 闭包改为防抖模式
