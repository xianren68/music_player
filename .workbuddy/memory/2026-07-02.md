## 技术要点

1. **GPUI `.when()` 语法**：
   - 正确：` .when(condition, |this| this.child(...))`
   - 闭包应返回 `this`（即 `Self`）

2. **`on_click` 闭包**：
   - 需要使用 `Fn` trait（可多次调用）
   - 如果闭包需要拥有 `SharedString`，需要在闭包内 `.clone()`

3. **后台文件对话框**：
   - 使用 `cx.background_spawn` 避免阻塞主线程
   - 避免 Windows 嵌套消息循环导致重入 panic

### 6. 标题栏拖动窗口
