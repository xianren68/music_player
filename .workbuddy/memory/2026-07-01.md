## 2026-07-01

- 修复 MusicPlayer 编译错误：结构体中 `total_time` 字段残留，删除后编译通过
- UI 调优三件事：
  1. **顶部按钮**：选中状态去掉背景色，只保留 SVG 颜色变化
  2. **侧边栏歌曲列表**：当前播放曲目添加 `t.active` 背景色高亮；序号替换为三条均衡器竖条
  3. **播放控制栏**：移除 `absolute` 定位和边框；改为流式布局居中；进度条容器限制 `max_w(420px)` 防溢出
- 第二轮修复：
  - **均衡器条**：固定 `h(18px)` 容器 + 三条 `w(3px)` 竖条
  - **全局布局**：center/main/body 统一用 `size_full()` 替代 `flex_1()`
- 第三轮修复：
  - **进度条消失**：`size_full()` 导致 center 占满高度把 player_bar 挤出去，改回 `flex_1()`
  - **均衡器动画**：新增 `eq_phase` 字段 + 150ms 定时器递增相位，用正弦波计算三条竖条高度（4~14px），实现类似 HTML 版 CSS `@keyframes bars` 的跳动效果
  - **颜色全面对齐 music-player.html**：bg `#0a0a0f`、surface `#12121a`、accent `#6c5ce7`、accent_light `#a29bfe`、fg `#f5f5fa`、muted `#a0a0b8`、muted_fg `#5a5a72`、border `rgba(255,255,255,0.06)`、active `rgba(108,92,231,0.12)`、hover `rgba(255,255,255,0.04)`
  - player_bar 加 `flex_none()` 防止被压缩
- 第四轮修复：
  - **panic: cannot read MusicPlayer while it is already being updated**：`build_sidebar` 中 `cx.entity().read(cx).eq_phase` 在 render 期间重复借用 entity 导致 double lease panic。改为将 `eq_phase` 作为参数从 `render()` 传入
- 第五轮修复（颜色对齐 HTML + 布局重构）：
  - **content 背景**：`t.bg`(#0a0a0f) → `t.surface`(#12121a)。HTML 的 `.app` 容器用 `--bg-surface` 不是 `--bg-base`
  - **topbar 透明度**：0.8 → 0.6，匹配 HTML 的 `rgba(10,10,15,0.6)`
  - **布局重构**：player_bar 作为参数传入 center，成为 center 的最后一个 child（flex_none），artwork 区用 flex_1 撑满上方，控制栏自然贴底
  - **进度条**：去掉 absolute 定位，改用 overflow_hidden + 固定 px 宽度填充条，解决乱飘问题
- GPUI 关键经验：
  - `flex_1()` 父容器需加 `overflow_hidden()` 才能正确收缩（等同 CSS `min-height: 0`）
  - render() 中不能 `cx.entity().read(cx)` 读自身字段，会触发 double lease panic，需通过参数传入
  - GPUI 的颜色层级：bg(base) 最暗 → surface(app容器) → 半透明面板(rgba(bg,0.4~0.6))
- 第六轮修复（**颜色终于正确！** + 布局改回垂直居中）：
  - **🔑 关键发现：GPUI 的 Hsla.h 范围是 0~1（不是 0~360°）**
    - 源码 `From<Hsla> for Rgba` 内部做 `h * 6.0 % 2.0`，所以 h=247 会被当 h=247（取模后 ≈ 红色）
    - 必须用 `h = CSS度数 / 360` 来转换
    - 新增 `css_hsl()` / `css_hsla()` 辅助函数做这个转换
  - **布局改为参考截图样式**：center（封面+信息）+ player_bar（进度条+控制）作为兄弟元素，整体在 main 中 `items_center().justify_center()` 垂直居中
