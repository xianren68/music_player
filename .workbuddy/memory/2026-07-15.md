### 推送代码到 GitHub 远程
- 用户新建远程仓库 `https://github.com/xianren68/music_player`，要求上传。
- 按用户偏好用 **HTTPS**（非 SSH）：`git remote add origin https://github.com/xianren68/music_player.git`。
- 本地原分支为 `master`，改名 `main` 再推送（`git branch -m master main`），契合 GitHub 默认分支，避免网页端显示空仓库；`git push -u origin main` 成功，`main -> main` 新建并设上游。
- 凭证走 Windows 凭据管理器（`wincred`，全局 `credential.helperselector.selected wincred`），本次推送正常、无凭证过期故障。
- 踩坑提醒：用 `git push ... | tail -N` 时输出会被缓冲到管道关闭（推送结束）才一次性打印，期间"零输出"≠卡住，别误判为凭证挂起；要看实时进度就不要接 `tail`，或用 `git push --progress`。
